# 백엔드 개념 단어장

백엔드 필수 개념 46개를 **암기 카드 · 퀴즈 · 오답노트**로 공부하는 사이트.

**사이트:** https://pakuyama.github.io/backend-study/

## 기능
- **암기 카드**: 앞면 용어 / 뒷면 설명·예시. 외웠어요/모르겠어요 표시, 못 외운 것만 보기
- **전체 목록**: 분야별 목록, 검색, 외움 체크
- **퀴즈**: 4지선다, 분야·문제 수·유형 선택
- **오답노트**: 틀린 개념 모음, 복습 퀴즈에서 맞히면 자동 삭제

진행 상황은 브라우저(localStorage)에 저장됩니다.

## 구조
| 파일 | 설명 |
|---|---|
| `index.html` | 원본 (내용·기능은 여기서 수정) |
| `build-web.js` | 원본을 웹페이지로 감싸 `docs/index.html` 생성 |
| `docs/` | GitHub Pages 배포 폴더 (빌드 결과물) |

## 수정 후 배포
```
node build-web.js
git add -A && git commit -m "..." && git push
```
푸시하면 1~2분 뒤 사이트에 반영됩니다.
